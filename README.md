# Banking Frontend Project
## Project Overview
thsi is a banking application frontend developed as part of an internship project.
## technologies  used
-HTML
-CSS
-JavaScript
-visual studio code
## Features
-UserLogin
-Banking Dashboard
-Account Details
-Money Transfer
-Transactions History
-User Profile
-Logout
-Page Navigation
-Responsive Frontend Design
## Project Structure
-index.html - Login page
-dashboard.html -Banking dashboard 
-account.html - Account details
-transfer.html - transfer money page 
-transactions.html - Transaction history page
-profile.html -  user profile page
-style.css - Login page styling 
-dashboard.css - Dashboard styling
## How to Run 
open `index.html` using live server in visual studio code.
